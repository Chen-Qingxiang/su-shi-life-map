# 全书章节地图审阅指南

本分支现可从章节下拉框切换第 1—14 章。建议审阅时按以下顺序进行：

1. 逐章确认标题、年代与摘要是否和读书笔记一致。
2. 检查路线首尾是否完整，尤其是第 7、12、13、14 章的长距离迁徙。
3. 检查同城空间是否有必要保留，避免把黄州、汴京、杭州、惠州、儋州压成一个点。
4. 重点复核低可信度坐标：古驿、旧寺、园亭、岭路和范围性地点。
5. 抽查作品卡片能否回到正确节点；作品全文目前不是验收范围。
6. 检查第 14 章是否按“廉州北归—常州逝世—郏城安葬”闭合。

## 易混地点

- 南都 / 南京应天府：今河南商丘，不是今南京。
- 金陵：今江苏南京。
- 郁林：本章按今广西玉林处理，不按桂林。
- 昌化军 / 儋耳 / 宜伦：均指海南儋州一带的不同历史称谓。
- 英州：今广东英德；惠州南贬途中和北归途中均经过。
- 大庾岭 / 梅岭：赣粤界地理门槛，第 12 章南越、第 14 章北越。
- 颍州：今安徽阜阳；颍昌 / 许昌是苏辙晚年所在，不可混为同一地。
