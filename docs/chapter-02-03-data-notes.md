# 第二、三章旅程数据说明

## 范围

本次新增《苏东坡新传》第二章“变法与党争”和第三章“马入尘埃”的章节旅程：

- 第二章：28 个节点、27 段路线、11 篇代表作品。
- 第三章：34 个节点、33 段路线、18 篇代表作品。

章节资料主要依据 Obsidian Vault 中：

- `Reading/苏东坡新传/02 变法与党争.md`
- `Reading/苏东坡新传/03 马入尘埃.md`

整理时优先采用笔记里的“年代与地点”“地点主线 / 地点层次”“事件线”“作品互证”。

## 数据粒度

节点不是只取凤翔、杭州、密州等大站，而是保留对阅读有解释力的中层节点，例如：

- 凤翔八观、太白山祈雨、章惇险游、凌虚台、扶柩归蜀、陈州与颍州；
- 孤山访僧、汤村盐河、湖州堤岸、新城山村、常润赈饥、别杭赴密、常山祷雨、超然台。

同一城市内无法可靠定位到具体遗址的地点，使用现代城市或区域近似坐标，并标为 `low` 或 `medium` certainty。

## 路线精度

路线按章节叙事节点顺序连接，只用于建立空间感，不表示精确的北宋航道、驿路、道路或城市内部路径。跨流域、折返与长期驻留阶段尤其不能把直线理解为真实交通线。

## 作品数据

本次先接入笔记“作品互证”中的 29 篇代表作品，并关联到相应节点。每条保留维基文库检索入口及校勘状态。

与第一章南行诗作不同，本次没有把全部作品正文直接嵌入仓库；长篇奏议、记文和题名异文仍应结合可靠点校本逐篇核对。页面会明确显示这一状态，避免把检索结果误当作最终校本。
